# CoreProIT v2

Premium agency-style portfolio for MD MEHEDI HASAN.

## Stack
- Next.js 15
- React 19
- Tailwind CSS
- Framer Motion
- Lucide React
- TypeScript

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```

## Vercel

Push to GitHub and import the repository into Vercel. No environment variables are required.
